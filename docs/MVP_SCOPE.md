# MotoLink MVP 范围

## 目标

MVP 的目标是验证“组队 + 实时位置 + 半双工对讲”是否能在真实骑行环境成立，并形成可继续演进的工程骨架。

## 本阶段包含

1. 开发环境手机号登录，不接短信供应商。
2. 附近车友列表与位置上报接口；陌生人位置只返回模糊坐标。
3. 创建车队、通过房间号加入、房间成员列表。
4. PTT 抢麦租约：申请、心跳续租、释放、超时自动回收。
5. 移动端按住说话状态机和原生能力桥接接口。
6. 骑行开始、轨迹点上报、结束与基础里程统计。
7. 管理端用户、车队和基础指标查看。
8. Docker Compose 本地环境与 CI。

## 明确不包含

- 正式短信、微信登录、Sign in with Apple。
- 已选定或已付费的 RTC、IM、地图、推送供应商。
- iOS PushToTalk、Android Foreground Service 的商用实现。
- 锁屏后台保活率、300ms 延迟和高速风噪指标承诺。
- 社区动态、图片上传、推荐流、评论、私信、内容审核运营。
- 支付、会员、广告、打赏、线下活动报名。
- 7×24 运维、救援调度或事故响应服务。

## 进入下一阶段的门槛

- 甲方确认运营主体、首发商店、目标地区和业务收费方式。
- 企业账号能够取得所需平台权限和第三方服务商业许可。
- 明确目标手机、头盔蓝牙设备、道路场景、网络条件和验收口径。
- 完成至少两家 RTC 的实车对比 POC。
